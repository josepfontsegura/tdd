Problem 1. If \phi(t) has energy E, then \langle\phi,\alpha\phi\rangle=\alpha E for any complex \alpha.

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 2. The conjugate falls on the second waveform, so \langle\phi,\alpha\phi\rangle=\alpha^*E.

(b) False

Statement 5, channel uses of a passband transmission.

(b) False

Statement 9, average symbol energy of a constellation.

Problem 4. In a Monte Carlo simulation, the average of the squared moduli of many symbols estimates the entropy H(X).

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 11. The average of the squared moduli estimates the average symbol energy \EE(|X|^2); the entropy is estimated by the average of -\log_2\Pr(x_i).

Problem 5. The binary entropy function h_2(p) vanishes for p=0 and p=1 and is symmetric around p=\tfrac12.

(a) True
(b) False

Show solution

The correct answer is (a) ★

Statement 13, zeros and symmetry of the binary entropy function.

Problem 6. The capacity of a channel is the smallest mutual information over all input distributions, C=\min I(X;Y).

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 16. The capacity is the largest mutual information over all input distributions, C=\max I(X;Y).

Problem 7. The complex AWGN channel is memoryless: the law of a sequence is the product of the laws of its symbols, W^n(\y|\x)=\prod_{i=1}^nW(y_i|x_i).

(b) False

The correct answer is (a) ★

Statement 18, the memoryless property of the AWGN channel.

Problem 8. With bandwidth and noise spectral density fixed, AWGN capacity is approximately proportional to power at low signal-to-noise ratio and grows logarithmically with power at high signal-to-noise ratio.

(a) True
(b) False

Show solution

The correct answer is (a) ★

Statement 20, the approximate low-SNR and logarithmic high-SNR dependence on power.

Problem 9. The maximum a posteriori (MAP) detector chooses, for the observed y, the symbol x that maximizes the channel law W(y|x), ignoring the prior.

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 21. That is the maximum likelihood detector; the MAP detector maximizes \Pr(x)W(y|x), the joint probability.

Problem 10. For a repetition code of odd length on a bit-flipping channel with flip probability p<\tfrac12, the ML decoder is the majority vote, whose error probability is the probability that more than half of the bits are flipped.

(a) True
(b) False

Show solution

The correct answer is (a) ★

Statement 22, ML decoding of the repetition code on the bit-flipping channel.

Problem 11. The Gaussian tail function Q(u)=\int_u^\infty\tfrac{e^{-t^2/2}}{\sqrt{2\pi}}\drm t equals \erfc\bigl(\tfrac{u}{\sqrt2}\bigr), with \erfc(u)=\tfrac{2}{\sqrt\pi}\smash{\int_u^\infty}e^{-t^2}\drm t.

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 23. Q(u)=\tfrac12\erfc\bigl(\tfrac{u}{\sqrt2}\bigr); the factor \tfrac12 is missing.

Problem 12. The shortest reversible mapping of k bits onto symbols of an M-point constellation has n=\lfloor k/\log_2M\rfloor symbols.

(a) True
(b) False

Show solution

The correct answer is (b) ★

Statement 24. It has n=\lceil k/\log_2M\rceil symbols, rounded up, so that M^n\geq2^k.
